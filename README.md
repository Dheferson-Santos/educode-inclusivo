# EduCode Inclusivo

Página web interativa desenvolvida para auxiliar estudantes iniciantes no aprendizado de algoritmos.

---

## Sobre o projeto

O **EduCode Inclusivo** é uma aplicação web simples e funcional criada como atividade prática da disciplina de **Programação Web I** do curso de **Engenharia de Software** da **Universidade do Estado do Pará (UEPA)**.

O objetivo é oferecer uma introdução clara e acessível ao conceito de algoritmo, permitindo que o usuário teste seus conhecimentos por meio de perguntas interativas com correção automática.

---

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (ES6+)

---

## Funcionalidades

- Explicação objetiva sobre o conceito de algoritmo
- Exemplo prático de algoritmo do cotidiano
- Atividade interativa com três perguntas de múltipla escolha
- Correção automática das respostas
- Feedback visual individual por pergunta
- Mensagem final personalizada conforme o desempenho do usuário
- Layout responsivo para desktop e dispositivos móveis
